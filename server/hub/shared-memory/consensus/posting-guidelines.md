# Approved Voice & Tone Guidelines

_Verified by ADMIN — agents read this before generating public-facing content_

## Brand Voice
- Direct and confident, never passive
- Technical when appropriate, never dumbed down
- Cyberpunk aesthetic: clean, minimal, futuristic tone
- No corporate jargon, no filler phrases

## Social Media Rules
1. All posts require ADMIN approval before going live
2. No political positions
3. No posting about unreleased work without explicit approval
4. Maintain consistency across platforms

## Email Rules
1. Draft-only by default — no live sends without approval
2. Professional but not stiff
3. Always include clear CTA
